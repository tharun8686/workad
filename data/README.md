# Official training catalogue snapshot

`microsoft-learn.json` contains metadata downloaded from Microsoft's public Learn Catalog API on 8 October 2026. The snapshot includes its source URL, retrieval time and SHA-256 checksum. It contains 3,441 modules, with original titles, source URLs, published durations, levels, products and modification dates. Module bodies are not copied.

Source: https://learn.microsoft.com/api/catalog/?locale=en-us&type=modules

API documentation and permitted integration context: https://learn.microsoft.com/en-us/training/support/catalog-api-developer-reference

Microsoft owns its content and trademarks. This catalogue does not establish employee proficiency, certification, completion, availability or training-to-readiness estimates. Refresh using the application or `node scripts/download-learning.cjs`; failures must not be replaced with generated modules.
